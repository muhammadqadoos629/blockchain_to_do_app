
# ChainTask - Decentralized To-Do List dApp

## Project Overview

ChainTask is a decentralized task management application
built using Solidity, HTML, CSS, JavaScript and ethers.js.

It allows users to create, view and complete tasks
through a smart contract deployed on the Ethereum
Sepolia test network.

## Features

- Connect MetaMask wallet
- Add new tasks
- View previously saved tasks
- Mark tasks as completed or pending
- Display total task count
- Separate task lists for different wallet addresses
- Retrieve tasks after refreshing the webpage

## Technologies Used

## Smart Contract Functions

1. addTask() - Adds a new task.
2. getMyTasks() - Retrieves the user's tasks.
3. toggleTask() - Changes task completion status.
4. getTaskCount() - Returns the total number of tasks.

## Installation and Setup

1. Download or clone this repository.
2. Open the project folder.
3. Make sure MetaMask is installed.
4. Select Ethereum Sepolia network.
5. Open the project using VS Code.
6. Run index.html through Live Server.
7. Connect your MetaMask wallet.
